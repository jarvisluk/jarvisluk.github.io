Gocus is a compact utility surface: it should read like a narrow desktop tool, not a large content page. Every value below is read from the CSS tokens the interface uses.

Type scale

Semantic roles over a compact 10–20px scale. Raw px sizes are not allowed in UI rules.

Display--type-display-sizeEmpty-state headings only
Page title--type-page-title-sizeApp header or top-level page
Heading 1--type-heading-1-sizePrimary panel headings
Heading 2--type-heading-2-sizeCards, dialogs, item titles
Body strong--type-body-strong-sizeStats and selected metadata
Body--type-body-sizeNormal copy, hashes, small controls
Caption--type-caption-sizeHelper text, timestamps
Micro--type-micro-sizeGraph labels, tiny badges
